# ENTRELINHAS

### *aquilo que eu penso, sinto e nem sempre consigo dizer.*

---

Este não é um projeto.

Não existe uma finalidade específica aqui.
Não existe código para executar, problema para resolver ou resultado para alcançar.

Existe apenas um espaço.

Um lugar para colocar em palavras aquilo que, algumas vezes, fica preso dentro de mim.

Pensamentos.
Dias bons.
Dias ruins.
Memórias.
Medos.
Pequenas alegrias.
Coisas que eu gostaria de dizer.
Coisas que talvez nunca sejam ditas.

Algumas páginas podem fazer sentido.

Outras talvez não façam nem para mim.

E tudo bem.

Este livro não precisa ser perfeito.

Ele só precisa ser verdadeiro.
